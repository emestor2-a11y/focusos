# FocusOS ЕГЭ — первый прототип

Мини-приложение для учёта времени подготовки к четырём предметам ЕГЭ. Сейчас это **клиентский прототип**: секундомер, сохранение завершённых сессий, статистика по предметам и последним 7 дням.

## Важно про токен Telegram
Токен бота был опубликован в переписке. Считайте его скомпрометированным: откройте `@BotFather`, выберите бота и выполните `/revoke`, затем получите новый токен. Не вставляйте токен в HTML/JavaScript, GitHub или этот репозиторий. Для текущего прототипа токен не нужен.

## Запуск на компьютере
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Выберите предмет → «Начать» → «Завершить».
4. Откройте «Статистика».

Для обычной локальной проверки этого достаточно. Данные сохраняются в localStorage браузера.

## Бесплатная публикация через GitHub Pages
1. Создайте аккаунт на GitHub, если его ещё нет.
2. Нажмите **New repository** и назовите репозиторий, например `focusos-ege`.
3. Загрузите в репозиторий `index.html`, `style.css`, `app.js` и `README.md` (именно содержимое папки, не zip).
4. Откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**.
6. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
7. Через минуту GitHub покажет адрес вида `https://ВАШ-ЛОГИН.github.io/focusos-ege/`.

## Как открыть как Telegram Mini App
Публикация на GitHub Pages даст HTTPS-сайт. Чтобы открыть его внутри Telegram, настройте бота через `@BotFather` после отзыва старого токена:
1. Выполните `/mybots` → выберите бота.
2. Откройте **Bot Settings → Configure Mini App** (названия пунктов могут немного отличаться) или настройте Main Mini App.
3. Укажите URL GitHub Pages.
4. Откройте бота и запустите Mini App.

В зависимости от текущего интерфейса BotFather может понадобиться установить кнопку меню через настройки бота. Секретный токен для самого сайта не требуется.

## Ограничения первого прототипа
- Данные пока хранятся только в браузере/на устройстве. Если открыть приложение на другом устройстве или у друга, история не синхронизируется.
- GitHub Pages — только статический хостинг; он не запускает Python-бота и не является базой данных.
- Если таймер закрыть до нажатия «Завершить», текущая незаконченная сессия не сохраняется.
- Следующий этап для соревнования с другом: добавить серверную базу данных и идентификацию через Telegram Web App initData. Токены и ключи базы должны храниться в секретах backend, не во фронтенде.
